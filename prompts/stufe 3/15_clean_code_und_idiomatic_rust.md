# Audit 15 — Clean Code and Idiomatic Rust

Date: 2026-10-25. Scope: `human-money-node`, both production Rust libraries, public APIs and error handling. Base HEAD: `d5be41f4e8a9662dffb5170b629191a950aab922`; inspected working tree contains pre-existing changes and was changing during execution. Audit only; no fixes applied.

## Findings

- **A15-01 / P2 — Public fraud APIs panic on mismatched signers.** `crates/humoco-sim-core/src/fraud.rs:645–750`: three constructors assert signer equality; even the boolean `check_ingress_conflict` calls a panicking constructor. An isolated executable linked against the built library reproduced the panic with two default envelopes and different `gateway_pubkey` values. The daemon's inspected evidence lookup uses the authenticated sender key (`network/transport.rs:993`); this does **not** establish a remotely reachable crash. This is an unsafe public API contract, not demonstrated memory UB.
- **A15-02 / P3 — Public simulation helper panics on a valid small network size.** `crates/humoco-sim-core/src/chaos.rs:33–82`: `simulate_60_40_partition_merge(1)` indexes an empty partition. Reproduced through the actual public library function. This affects simulations, not the production request handler.
- **A15-03 / P3 — Internal storage invariants are externally mutable.** `crates/humoco-node/src/storage/engine.rs:29–49,676–685` exposes maps, indexes, queue sender and synchronization handles publicly. Callers can modify lock/index state without the intended insertion/durability methods. Existing `pub(crate)` durability metadata shows partial encapsulation. No wire exploit demonstrated. Generic `NodeError::{Network,Crypto,Daemon}(String)` also loses structured causes (`src/error.rs:24–74`); typed Quinn variants are already present and should remain the model.
- **A15-04 / P2 — Mandatory standard validation is not clean.** `cargo test-std --offline` exited 101: `quorum_assembly_tests.rs:735` refers to missing `PeerInfo.consecutive_failures` (E0609). That field access was changed concurrently; the bounded rerun compiled, then ended with exit124 after180s: completed targets reported417 passed,1 failed,14 ignored. `phase11_wire_level_adversarial_tests::test_valid_signatures_for_wrong_request_or_tls_context_never_form_quorum_wire` failed at line1811 (observed send count1, expected2; request itself failed closed with HTTP503). The final status-reconciliation target was unfinished. No complete standard-suite result or successful protection test can be claimed from this run. This concerns the observed changing working tree, not a regression introduced by this audit.

Other observations: fixed-size hash conversions, guarded wire conversion and QR's fixed `0..15` match do not demonstrate input-triggered panics. Pedantic Clippy completed with exit 0: core library 985 warnings, node library 1437 warnings (includes style/documentation warnings; not 2422 security defects). Root re-exports and primitive hash aliases merit gradual API cleanup, not wholesale changes without caller analysis.

## Integrated fix plan

1. **A15-04 first:** retain the concurrent field-access repair, independently reproduce the wrong-context QUIC send-count failure, and determine whether scheduling, fixture admission or production behavior caused it. Investigate the unfinished status-reconciliation target; then run the standard suite to completion. Preserve the adversarial assertions rather than weakening them to obtain green results.
2. **A15-01:** introduce a typed `FraudBuildError::SignerMismatch` and fallible constructors; make `check_ingress_conflict` return `false` for unrelated signers. Migrate all wrappers/callers. Test unequal signers, valid same-signer proofs and malformed evidence; retain real QUIC receiver tests before claiming network panic freedom.
3. **A15-02:** validate node count and checked `u16` conversion before constructing groups. Return a typed error for unsupported partitions; test N=0,1,2 and identifier-capacity boundaries without allocating an oversized mesh.
4. **A15-03:** inventory external callers, privatize mutable maps/queue handles incrementally, and expose bounded query/mutation methods that preserve indexes and durability gates. Preserve necessary integration-test hooks deliberately. Replace string wrappers where callers need machine-readable decisions, retaining source errors and useful IDs/paths.
5. Re-run standard tests and pedantic Clippy; prioritize correctness/casts/API changes before cosmetic warnings. Accept when malformed public inputs return errors, storage callers cannot bypass invariants, and the mandatory suite compiles and passes.
